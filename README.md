## 八股总结

1️⃣ __为什么要自定义 Dataset__

Dataset 用来统一“如何读取一条数据”，是数据层的标准接口。
在 PyTorch 中，自定义 Dataset 是为了统一数据访问方式。
Dataset 负责定义两个核心方法：__len__ 和 __getitem__，前者表示数据集大小，后者定义如何根据索引获取一条样本。
这样无论数据来自文件、数据库还是内存，都可以用统一方式访问，并且可以和 DataLoader 无缝配合进行批量加载。


__为什么不直接用 list / numpy 数组？__

因为 Dataset 支持更复杂的数据读取逻辑，比如懒加载、大数据集按需读取、在线数据增强等，而 list 无法很好支持这些场景。

2️⃣ __为什么要用 DataLoader__

DataLoader 的作用是对 Dataset 进行封装，实现批量加载（mini-batch）、数据打乱（shuffle）、并行加载（多线程）等功能。
它可以自动把单条样本组织成 batch，提高训练效率，同时利用并行机制加速数据读取，是深度学习训练中数据输入的重要组件。


__mini-batch 为什么重要？__

DataLoader 支持 mini-batch，是因为 mini-batch 在计算效率、内存占用和训练稳定性之间取得了平衡，是现代深度学习的标准训练方式。

__为什么不用 full batch 或 batch=1？__

full batch 计算成本高、内存占用大；batch=1 梯度噪声大且并行效率低；mini-batch 是折中方案。

3️⃣ __为什么回归任务常用 MSELoss__

MSE 衡量预测值和真实值之间的“平方误差”，适合连续值回归。
它具有良好的数学性质（连续、可导），便于使用梯度下降优化，同时对较大的误差惩罚更强，因此在回归问题中非常常用。
从概率角度看，MSE 对应假设误差服从高斯分布时的最大似然估计，因此具有理论依据。


Q：为什么是平方，不是绝对值？

平方损失对大误差更敏感，有助于更快纠正大的偏差；同时它是光滑可导的，优化更方便。

Q：那 L1 Loss 呢？

L1 对异常值更鲁棒，但梯度不连续；MSE 对大误差更敏感，收敛更平滑。

4️⃣ __为什么训练时要分 train 和 val__

为了评估模型的泛化能力。
训练集用于学习模型参数，而验证集用于在未参与训练的数据上评估模型性能。
如果只看训练集，模型可能只是记住数据（过拟合），而验证集可以帮助判断模型是否真正学到了规律。


Q：为什么不能用测试集调参？
测试集应该作为最终评估标准，如果参与调参会导致信息泄露，使评估结果不再客观。

## 遇到问题解答

### 1️⃣ 为什么要固定随机种子（seed）？

> 固定随机种子是为了让实验结果具有可复现性。

在深度学习中，很多过程都涉及随机性，比如参数初始化、数据打乱、数据划分等。  
通过设置随机种子（seed），可以让这些随机过程从同一个初始状态开始，从而使实验结果在多次运行中尽量一致，方便调试和对比实验。


- 影响的环节包括：数据生成、模型初始化、DataLoader shuffle、train/val 划分等  
- 本质是“伪随机数生成器的起点控制”
---

### 2️⃣ `super().__init__()` 是什么？为什么要写？


> 调用父类的初始化函数，确保继承体系正确初始化。


在 Python 面向对象中，`super().__init__()` 用于调用父类的构造函数。  
在 PyTorch 中，模型通常继承自 `nn.Module`，调用 `super().__init__()` 可以确保父类内部的参数管理、模块注册等机制正确初始化。

### 语法理解
- `super()`：获取父类对象
- `__init__()`：调用父类初始化函数
- 两个括号分别表示：调用 `super` 和调用函数
- 如果父类构造函数有参数，需要传入；但在 `nn.Module` 中通常为空
- 不调用可能导致模型参数无法正确注册

---

### 3️⃣ `nn.Linear` 为什么会自动有参数？参数个数怎么确定？

> `nn.Linear` 内部自动创建 weight 和 bias，参数数量由输入输出维度决定。

`nn.Linear(in_features, out_features)` 表示一个线性变换层，其数学形式为：

$` y = xW^T + b `$

其中：
- `weight` 形状为 `[out_features, in_features]`
- `bias` 形状为 `[out_features]`

总参数个数为：

$` out\_features × in\_features + out\_features `$

### 举例
- `nn.Linear(1,1)` → 2 个参数（w + b）
- `nn.Linear(100,10)` → 1000 + 10 = 1010 个参数

### 加分点
- 参数是 `nn.Parameter` 类型，会自动被 `model.parameters()` 收集
- 这些参数由 optimizer 统一管理和更新

---

### 4️⃣ 为什么 `model(x)` 就是前向传播？


> `model(x)` 实际调用的是 `nn.Module.__call__()`，内部再调用 `forward(x)`。

在 PyTorch 中，模型继承自 `nn.Module`，该类实现了 `__call__` 方法。当执行 `model(x)` 时，本质是调用 `__call__()`，而 `__call__()` 内部会自动执行 `forward(x)`。

因此：

> `model(x)` 是前向传播的标准入口，而不是直接调用 `forward`。


---

### 5️⃣ 为什么要用 `loss.item()`？

> 把 tensor 转成 Python 数值，方便统计和打印。


在 PyTorch 中，loss 是一个 tensor 对象。`loss.item()` 用于将单元素 tensor 转换为 Python 的 float 数值，便于：

- 累加 loss
- 打印日志
- 计算平均值
- `item()` 只适用于单值 tensor

---

### 6️⃣ 为什么使用 mini-batch？`with torch.no_grad()` 是什么？

---

#### （1）mini-batch 为什么最常用

> 在计算效率、内存占用和训练稳定性之间取得平衡。


mini-batch 是深度学习中最常用的训练方式，相比：

- batch=1：梯度噪声大，效率低  
- full batch：内存占用高，更新慢  

mini-batch 能：

- 利用并行计算提高效率  
- 降低梯度方差，提高稳定性  
- 控制内存使用  

---

#### （2）`with torch.no_grad()` 是什么

> 在该代码块中关闭梯度计算。

`with torch.no_grad()` 表示在这个代码块中不记录计算图，也不计算梯度。常用于验证或推理阶段，因为这些阶段不需要反向传播。

#### Python 语法解释
- `with` 是上下文管理器
- 表示“进入一个特殊环境，执行代码，然后自动退出”

#### 加分点
- 优点：更省内存、更快
- 推理阶段必须使用（规范写法）

---


### 7️⃣ 学习率（learning rate）大小的影响

> 控制参数更新步长，影响收敛速度和稳定性。


学习率决定每次参数更新的步长：

$` \theta = \theta - lr \cdot \nabla L `$

- 学习率过大：
  - 容易震荡甚至发散
  - loss 波动大，不稳定  

- 学习率过小：
  - 收敛稳定
  - 但速度慢，需要更多 epoch  

因此需要在收敛速度和训练稳定性之间进行权衡。

#### 加分点
- 常用技巧：learning rate scheduler（学习率衰减）
- 不同模型/任务的最优 lr 不同

## 问题总结
### 1. 线性分类边界理论上最少需要多大的隐藏层？和层数、epoch 有什么关系？

如果分类边界本身就是一条直线，比如：

$`x_1 + x_2 > 0`$

那么这是一个**线性可分问题**。

这种情况下：

> **不需要隐藏层。**

也就是说，直接用一个线性分类器就够了，例如：

- 输入维度：2
- 输出类别：2

本质上可以直接用一层线性层完成分类。

---

#### 1.1 那为什么 MLP 也能做？

因为 MLP 包含线性层，也能表达线性边界。  
只是对于本来就线性可分的问题来说，MLP 不是“必须”，而是“也可以”。


#### 1.2 对于不同分类边界，隐藏层理论上最少几维？

这取决于：

- 边界是不是线性的
- 边界有多复杂
- 你允许用几层网络


#### 情况 1：线性边界

> 一层线性层就够，不需要隐藏层。


#### 情况 2：非线性边界
例如：
- 圆形边界
- 环形边界
- 多段折线边界

这种问题通常就需要：

- 隐藏层
- 非线性激活函数
- 可能还需要更多层或更大的 hidden_dim


#### 1.3 隐藏层维度、层数、epoch 分别决定什么？

这三个东西一定要分开理解。

#### （1）隐藏层维度 / 层数
决定的是：

> **模型表达能力（capacity）**

也就是模型“能不能表示出这个函数 / 这个边界”。


#### （2）epoch
决定的是：

> **模型有没有学到**

也就是即使模型理论上能表示，如果训练轮数不够，也可能还没学出来。

### 2. `argmax(logits, dim=1)` 里的 `dim=1` 怎么理解？`labels.size(0)` 里的 `0` 怎么理解？

这部分最重要的是先记住一句话：

> **dim 表示“沿着哪个维度操作”。**

$`dim=i`$的意思就是（第i维的下标不一样，其他维下标一样）这些数作为一个整体进行某个运算。比如4维数组，dim=1就是$` [i][x][j][k] `$（i,j,k为定值），x从0到shape[1]为一个整体运算
